Tentang WeatherLive

WeatherLive Global Dashboard adalah aplikasi cuaca berbasis Progressive Web App yang menampilkan data cuaca real-time, forecast 3 hari, grafik suhu per jam, kualitas udara, UV Index, smart recommendation, kota favorit, pencarian lokasi spesifik, dan mode offline terbatas.

Data cuaca berasal dari WeatherAPI.com Forecast API, sedangkan pencarian lokasi detail dibantu oleh OpenStreetMap/Nominatim.

Teknologi: Flask, HTML, CSS, JavaScript, Chart.js, PythonAnywhere, GitHub, WeatherAPI, OpenStreetMap, dan PWA.
